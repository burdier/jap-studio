En Jap Studio (Hay)

  • Hay Synth nativo importa .vital, .vitalbank y .fxp (Serum) con wavetables reales
  • Spectrum, Comp con sidechain, Warp y Audio → MIDI viven dentro del DAW
  • El Explorer analiza transiente, brillo, bandas y tono al instante
  • Servidor MCP nativo: la IA analiza tus samples, compone y mezcla en vivo
  • Dos ventanas comparten sesión por P2P transfiriendo samples automáticamente
  • Un solo .flatpak en Linux o un .zip portable en Windows x64

Flexible por diseño

Motor RT sin clics

Mezcla multipista con PDC, Hay Synth band-limited (0 aliasing), sampler PCM bit-exacto para Drums, cambio de BPM en vivo sin pausar y colas rtrb sin bloqueos ni timers de UI.

Todo es una acción

Toda operación ejecutable es una acción al estilo REAPER. Teclado, ratón, barra :, scripts Lua y servidor MCP llaman exactamente al mismo controlador.

Ojos acústicos

Un analizador DSP offline (0% impacto en audio RT) mide transiente, ataque, decay, brillo, bandas Sub/Grv/Med/Agd y tono tanto en la UI como para agentes de IA.

Linux, Windows y Export Pro

PipeWire/ALSA en Linux, WASAPI en Windows y CoreAudio en macOS. Exportación con medición EBU R128 (LUFS-I, True Peak 4×), stems alineados y WAV nativo sin dependencias externas.

Tu estilo y tus rutas

4 temas curados —Cyberpunk Studio, Daylight Studio y Cuaderno Claro/Oscuro (nacidos de esta misma libreta)—, Vim opcional y pestaña Rutas centralizada para VST3/VST2/CLAP, SoundFonts, presets y kits.

Colaboración P2P real

El formato .loro guarda Arrangement, Drums, FX, wavetables y automatización. En vivo, Loro + Iroh une sesiones solo con un token, transfiere tus WAVs y hace bypass elegante si falta un VST3.

Descárgalo en Linux o Windows en 1 minuto

Sin compilar ni configurar dependencias: descarga directa y rápida desde Cloudflare R2 (v0.8.0), con colaboración P2P y servidor MCP integrados de serie.

↓ Descargar Linux (.flatpak · 267 MB) ↓ Descargar Windows x64 (.zip · 77 MB) ☕ Regalar un café (PayPal)

1 · Linux (Flatpak único)

Un solo archivo .flatpak (267 MB) con motor release, libsfizz y 23 bancos SoundFont listos:

↓ Descargar .flatpak 
flatpak install --user jap-studio-0.8.0-x86_64.flatpak
flatpak run io.github.burdier.JapStudio

2 · Windows x64 (Portable)

Descarga JapStudio-Windows-x64.zip (~77 MB), descomprime y abre jap-studio.exe. Incluye audio WASAPI, exportación WAV nativa y MCP por TCP local.

↓ Descargar Windows x64 (.zip)

Para compilar el paquete Windows desde Linux:

bash scripts/build-windows.sh

3 · Tocar juntos en vivo (P2P)

Usa Archivo → Compartir sesión para copiar el token hay-live:... y compártelo para conectar por Archivo → Unirse. Tus WAVs y wavetables se transfieren solos.

Añade carpetas de SoundFonts, VST3 o presets .vital/.fxp desde Configuración → Rutas.

4 · Conectar con IA (MCP)

Con Jap Studio abierto, Gemini CLI o Claude pueden analizar tus samples y producir en vivo con 22 herramientas:

# Linux (Flatpak)
flatpak run io.github.burdier.JapStudio --mcp
# Windows
jap-studio.exe --mcp
